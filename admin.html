科目開關

開啟學員網站預覽

重要：管理頁與學員頁已分開，但這是靜態網站版本。此頁無法直接修改 GitHub 伺服器上的檔案。要讓全部學員套用設定，必須下載設定檔後覆蓋網站原有的 bank-config.js。不需把 admin.html 公開上傳；建議僅由管理員本機保存。

發布步驟

  1. 勾選想開放的科目；取消勾選代表暫停開放。
  2. 按「下載開放設定檔」。
  3. 將下載的 bank-config.js 上傳到 GitHub Pages 網站的根目錄，覆蓋同名檔案。
  4. 等 GitHub Pages 部署完成，再用手機重新整理學員網站測試。

若學員先前已打開網站，必須重新整理才能讀取新設定。瀏覽器快取可能導致短暫延遲；此版本是介面開放控制，不是保密或考試防作弊系統。
